# OOP Labs

Java labs from my Object-Oriented Programming module at TU Dublin. New labs are added as the module goes on.

## Structure

Each lab has its own package inside [`src/`](src), named after the lab (e.g. `lab1`, `lab2`).

## Running the code

1. Clone the repo: `git clone https://github.com/nady-lab/OOP.git`
2. In Eclipse: **File → Import → Existing Projects into Workspace** and select the folder.
3. Open the lab's main class and click **Run**.

## Tools

Java, Eclipse IDE
